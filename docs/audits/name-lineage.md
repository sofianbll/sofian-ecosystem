# Noms et identités

Un nom similaire ne prouve ni continuité ni remplacement.

## Registre initial

| Nom littéral | Type candidat | État de la relation | Remarque |
|---|---|---|---|
| `Sofian OS` | vision / projet / système selon l’époque | `to_reconstruct` | présent dans Notion et Obsidian |
| `SOFIAN OS V2` | version documentaire | `historical` | DOCX et synthèse ancienne |
| `Sofian OS V1` | synthèse historique | `historical` | reconstitution créée plus tard |
| `Sofian OS V3` | phase d’architecture abstraite | `historical` | relation exacte à confirmer |
| `Sofian OS V4` | modèle actuel dans le vault | `current_canon_candidate` | contenu canonique à vérifier par domaine |
| `Sofian-OS` | nom du vault actif | `confirmed_tool_identity` | outil/adaptateur, pas automatiquement le système |
| `Sofian's Vault` | ancien vault | `confirmed_historical_source` | lecture seule explicite |
| `notion-to-obsidian` | conversion locale | `confirmed_derived_archive` | pas preuve d’une migration complète |
| `Jarvis` | agent / interface selon le contexte | `to_reconstruct` | préserver chaque usage daté |
| `Jarvis Agent` | projet et configuration agentique | `historical_and_current_candidate` | relation à Jarvis OS ouverte |
| `Jarvis OS` | architecture cible historique | `historical_intent` | déploiement non prouvé globalement |
| `Sofian Ecosystem` | méta-architecture et chantier | `active_project_identity` | cible encore non définie |
| `Ultimate Sofian OS — Architect & Build Sofian Life Space` | nom de chantier historique | `historical_alias_candidate` | équivalence à prouver |

## Règle

Tant que la relation n’est pas prouvée, conserver deux entrées séparées. Une correction de Sofian invalide les recommandations dérivées de la mauvaise identité.
