# Noms et identités

Un nom similaire ne prouve ni continuité ni remplacement.

## Relations intégrées depuis AUD-001

| Nom A | Nom B | Verdict | Limite |
|---|---|---|---|
| page Notion `Sofian OS` | export local `Sofian OS.md` | `confirmed` | correspondance bornée par titre, `notion-id` et lien ; ne couvre pas les versions ultérieures |
| `Sofian OS V3 - Architecture Système.md` | `Sofian OS.md` | `confirmed` | même lignée de fichier par renommage Git R100 ; pas une fusion générale des noms |
| page/export Notion `Sofian OS` | projet de l’ancien vault `Sofian OS` | `unresolved` | aucun locator direct entre les deux |
| page Notion `Sofian OS` | DOCX `SOFIAN OS VERSION 2.0` | `unresolved` | nom et date proches, sans référence croisée directe |
| DOCX `SOFIAN OS VERSION 2.0` | note `Sofian OS V2 - Synthèse Jarvis Personnel` | `unresolved` | thèmes proches, sans citation directe du DOCX |

Les désignations V1–V4 prouvent des documents, cadrages et journaux historiques. Elles ne prouvent pas des releases logicielles livrées.

## Règle

Tant que la relation n’est pas prouvée, conserver deux entrées séparées. Une correction de Sofian invalide les recommandations dérivées de la mauvaise identité.
