## États de couverture

- `brief_ready` — question et sources préparées ;
- `collecting` — collecte en cours dans une session autorisée ;
- `reported` — rapport reçu, pas encore contre-vérifié ;
- `reviewed` — citations décisives vérifiées ;
- `integrated` — conclusions intégrées aux registres ;
- `blocked` — source ou identité manquante ;
- `superseded` — remplacé par un workstream référencé.

## Ajouter un workstream

1. prouver qu’il n’est pas couvert ailleurs ;
2. attribuer un ID stable ;
3. copier `templates/audit-brief.md` ;
4. borner sources, dates et questions ;
5. déclarer les mutations interdites ;
6. choisir le rapport et la review attendus ;
7. ne créer une TaskNote que si Sofian décide de planifier son exécution.
