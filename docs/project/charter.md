# Charte

## Mission

Construire une vision globale, traçable et maintenable de Sofian Ecosystem depuis ses premières formes jusqu’à aujourd’hui, puis utiliser cette connaissance pour définir avec Sofian un écosystème cible cohérent et une transition réalisable.

## Résultat utile

À terme, Sofian doit pouvoir répondre sans revisiter tous ses anciens outils :

1. ce qui a existé, été décidé, tenté et réellement livré ;
2. ce qui existe et fait autorité aujourd’hui ;
3. les besoins encore couverts, partiellement couverts ou absents ;
4. les options raisonnables pour la cible ;
5. les changements à conduire, dans quel ordre et pourquoi.

## Principes non négociables

- vie et besoins avant systèmes et outils ;
- preuve directe avant mémoire ou résumé ;
- faits, hypothèses, idées et décisions séparés ;
- une autorité par fait précis ;
- lecture seule avant consentement exact ;
- réversibilité et petits lots ;
- confidentialité par minimisation ;
- validation finale par Sofian ;
- progression visuelle adaptée au TDAH.

## Droits de décision

| Sujet | Décideur |
|---|---|
| Faits observables d’une source | source directe + vérification |
| Interprétation et recommandation | Jarvis, explicitement signalée |
| Besoin personnel validé | Sofian |
| Frontière système et responsabilité cible | Sofian après comparaison |
| Mutation, migration ou publication | Sofian par lot exact |

## Non-objectifs

- centraliser toutes les données ;
- copier les anciens outils ;
- déclarer un système obsolète sans décision ;
- produire une architecture idéale spéculative ;
- automatiser avant d’avoir un workflow compris ;
- remplacer TaskNotes par un backlog Markdown.
