# Cible acceptée

## État

**Aucune architecture cible n’a été acceptée.**

Ce vide est intentionnel : le chantier doit d’abord reconstruire l’histoire, l’état actuel et les besoins.

## Contrat d’acceptation

Une cible entre ici uniquement si :

- Sofian comprend ses conséquences ;
- les options et le statu quo ont été comparés ;
- les faits et hypothèses sont séparés ;
- les autorités et responsabilités sont explicites ;
- plusieurs scénarios réels la supportent ;
- les coûts et risques sont acceptés ;
- une condition de réexamen existe.

Une cible acceptée est versionnée et révisable ; elle n’est pas une promesse de futur certain.
