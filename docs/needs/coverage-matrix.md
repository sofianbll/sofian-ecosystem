## Lecture

- `couverture` : `full`, `partial`, `none`, `unknown` ;
- plusieurs systèmes peuvent contribuer à un besoin ;
- une cellule ne transfère jamais l’autorité d’un fait ;
- une option n’est pas une décision ;
- la matrice éclaire la cible, elle ne la génère pas automatiquement.
