# Daily Start

## Besoin

Réduire le coût de décision et de démarrage : savoir quoi faire maintenant sans parcourir tout le système.

## Parcours proposé

```text
TaskNotes et projets → anomalies visibles → 3 options maximum
                    → choix humain → contexte → démarrage accompagné
```

## Sortie envisagée

- une action principale et jusqu’à deux actions secondaires ;
- raison du classement ;
- provenance ;
- certitude et données périmées ;
- aucune mutation pendant la première version.

## État

**Proposé, non construit.** Une todo de session a été marquée `in_progress`, mais aucune autorisation de build ni aucun code Daily Start n’a été enregistré.

## Risques

- classer avec des tâches périmées ;
- confondre recommandation et décision ;
- produire un brief décoratif sans aider au démarrage.
