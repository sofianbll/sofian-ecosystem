# Jarvis Socle v0.1 - Tester trois scénarios réels

## Outcome

Le brief est accepté sur trois situations réelles et ne masque ni conflit, ni preuve manquante, ni indisponibilité.

## Dépendance

Commencer seulement après [[Jarvis Socle v0.1 - Construire le brief en lecture seule]].

## Scénarios

1. **Journée normale** — plusieurs projets et tâches : trois priorités maximum, correctement sourcées.
2. **État contradictoire** — TaskNote et projet divergents : conflit visible, aucune réconciliation silencieuse.
3. **Source indisponible ou preuve absente** — `indisponible` ou `non établi`, jamais un faux vide.

## Definition Of Done

- [ ] Les trois fixtures ou cas réels sont documentés.
- [ ] Le résultat attendu est explicite pour chaque cas.
- [ ] Les trois exécutions sont rejouables.
- [ ] Aucune mutation non autorisée n’est observée.
- [ ] Les résultats réels sont conservés dans le handoff du projet.
