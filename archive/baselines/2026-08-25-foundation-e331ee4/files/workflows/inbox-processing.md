# Inbox Processing

## Besoin

Décider rapidement ce qu’une entrée devient sans la transformer automatiquement en tâche.

## Parcours cible

```text
Entrée → clarifier → tâche / projet / attente / référence / suppression proposée
```

## Autorités

- l’entrée originale reste la preuve de son contenu ;
- Sofian décide de sa destination ;
- TaskNotes porte l’état d’une action créée ;
- Sofian OS porte le projet ou la ressource résultante.

## État

**Documenté, non livré par Jarvis.** Le processus humain existe dans `SRC-V4`. Aucun moteur universel de classification n’a été vérifié.

## Critères d’acceptation

- destination explicite ;
- provenance conservée ;
- incertitude visible ;
- aucune mutation sans accord ;
- cible relue après écriture.

## Manques

Contrat d’entrée unifié, traitement des doublons et cas réels d’acceptation : `[À CONFIRMER]`.
