# État de Sofian OS

## État actuel

Le cockpit documentaire et les schémas de projets/tâches existent. Les routines quotidiennes sont définies mais leur usage régulier n’est pas démontré.

## Limites et risques

- notes de validation Jarvis potentiellement trop affirmatives ;
- friction de capture mobile ;
- surcharge lors du choix de la prochaine action ;
- confusion possible entre preuve externe et déclaration locale.

## Prochaines décisions

1. revoir explicitement les documents contestés avant de les appeler validés ;
2. choisir un seul besoin quotidien pour le prochain incrément Jarvis ;
3. conserver Sofian OS comme cockpit sans créer de second tracker.

Aucune migration du vault n’est décidée.
