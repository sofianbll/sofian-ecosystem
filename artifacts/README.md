# Artefacts

## État

Deux cartes HTML actives sont importées sous [maps/](maps/README.md) : architecture Niveau 0 et capacités transverses. Leurs copies correspondent octet pour octet aux originaux sous `SRC-ARTIFACTS`.

La carte Autorité contestée n’est pas active : elle réside dans [l’archive contestée](../archive/artifacts/disputed/README.md).

## Contrat d’import

Chaque artefact copié enregistre sa provenance, son nom original, sa date, son SHA-256, son statut et sa raison d’activation ou d’archivage. Les fichiers HTML bruts restent inchangés ; leur README voisin porte les métadonnées documentaires.
