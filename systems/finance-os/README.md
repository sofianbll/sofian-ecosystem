# Finance OS

Finance OS est un système spécialisé pour les états financiers qu’il persiste réellement. Il ne constitue ni la vérité bancaire primaire ni un système commercial complet.

## Responsabilités démontrées

- catalogue interne des comptes ;
- provenance et état des imports ;
- transactions normalisées importées ;
- éléments de cashflow ;
- index et statut de documents.

## Autorités absentes

Clients, missions, devis, factures émises et rapprochement facture-paiement restent non établis.

## Dépendances

[Homelab-OS](../homelab-os/README.md) pour le déploiement, fichiers/banques pour les preuves d’origine et Jarvis seulement comme lecteur futur.
