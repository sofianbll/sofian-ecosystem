# OpenCode

OpenCode est un environnement agentique utilisé par Sofian pour du travail de développement et possède un historique de sessions exploitable en lecture seule.

## Position confirmée

OpenCode est **conservé pour un usage futur**. Il n’est ni obsolète, ni supprimé, ni remplacé définitivement par Hermes.

## Responsabilités actuelles démontrées

- exécuter des sessions de travail OpenCode ;
- conserver leur historique dans sa base canonique ;
- fournir du contexte précis sur les travaux passés.
